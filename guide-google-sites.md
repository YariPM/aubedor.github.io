# Guide — Reproduire le site sur Google Sites

## Structure recommandée

Crée ces **pages** dans Google Sites :

| Page | Contenu |
|---|---|
| Accueil | Présentation + citation du Capitaine |
| Hiérarchie | Tableau des rangs |
| Magie | Les types de magie acceptés |
| Règles | Code d'honneur (7 règles) |
| Recrutement | Critères + formulaire |

---

## Thème sombre dans Google Sites

Google Sites ne supporte pas le CSS personnalisé nativement, mais tu peux :

1. **Thème sombre natif** : `Paramètres > Thème > Sobre / Minuit` — choisis le plus sombre disponible.
2. **Couleur principale** : `#c9a84c` (or) — à définir dans les couleurs du thème.
3. **Police** : Cinzel (disponible via Google Fonts dans Sites) pour les titres.

---

## Conseils par section

### Accueil
- Ajoute une **image d'en-tête** sombre (fond de château / ciel nocturne).
- Mets le titre **"L'Aube d'Or"** en grand avec la police Cinzel.
- Sous-titre : *"Gardiens de la noblesse. Porteurs de lumière dans les ténèbres."*

### Hiérarchie
Utilise un **tableau Google Sites** (Insérer > Tableau) :

| Rang | Titre | Titulaire |
|---|---|---|
| ⭐⭐⭐ | Capitaine | [Ton pseudo] |
| ⭐⭐ | Vice-Capitaine | Vacant |
| ⭐ | Chevalier d'Or | — |
| — | Chevalier | — |
| — | Aspirant | — |
| — | Recrue | — |

### Règles
Liste numérotée (Insérer > Liste numérotée) avec les 7 articles du code d'honneur.

### Recrutement
Intègre un **Google Form** (Insérer > Formulaire) avec les champs :
- Pseudo
- Type de magie
- Expérience RP
- Motivation

## Alternative : héberger le fichier HTML

Si tu veux utiliser le fichier `index.html` tel quel :
- **GitHub Pages** (gratuit) : crée un repo public, dépose le fichier, active Pages.
- **Netlify** (gratuit) : glisse-dépose le fichier sur netlify.com/drop.
- **Carrd.co** : importer le HTML dans l'éditeur.
